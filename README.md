# Quiz Playground — Cartoon Ladki

A smooth, responsive quiz playground with built-in quizzes, categories, timed rounds, custom quiz creation, results review, personal leaderboard, local persistence and JSON backup export.

## Developer
Cartoon Ladki

## Run
Open `index.html` or deploy the repository as a static site.

## Data
Custom quizzes and attempts are stored locally in the browser. No remote account or database is required in this version.
